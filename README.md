# 📚 읽다만

> 가장 편하게 병렬 독서를 이어가는 방법

**읽다만**은 동시에 여러 권의 책을 읽는 사람들을 위한 독서 관리 앱입니다.  
읽고 싶은 책이 많아 시작만 해두고 흩어졌다면,  
읽다만에서 **모으고 · 이어 읽고 · 완독**까지 깔끔하게 관리할 수 있습니다.

음악 플레이어처럼 *이어서 읽기*를 중심으로  
진행률, 메모, 통계가 한 화면에 정리됩니다.

---

## ✨ 주요 기능

### 📚 나의 ‘읽다만’을 모아보기
- 상태별 선반 관리  
  **읽는 중 / 읽고 싶은 / 잠시 쉼 / 완독**
- 홈 최상단 **이어서 읽기 카드**  
  → 가장 최근에 읽던 책으로 1탭 복귀
- **우선순위 핀**  
  → 이번 주 집중할 1–3권 고정

---

### ✍️ 기록은 필요한 것만, 간단하게
- 시작할 때 **첫인상 카드**  
  (읽는 이유, 기대, 한 문장)
- 읽는 중 **한 줄 기록 / 인용 / 메모**를 빠르게 저장
- **페이지 / 퍼센트 슬라이더**, **세션 타이머**로 진행률 자동 업데이트
- **평점 · 키워드**로 마무리 → 한눈에 보는 **완독 리포트**

---

### 🔔 동기부여를 위한 넛지
- **주간 목표** (분 / 페이지 / 세션)
- **연속 읽기(스트릭) 배지**
- 상황형 리마인드  
  - “오늘 10분만 읽어볼까요?”
  - “남은 챕터가 1개예요”
- 기본 알림: **월 / 금 원하는 시간** (설정 가능)

---

### 📊 통계로 보는 나의 독서 습관
- 주간 · 월간 독서량
- 가장 많이 읽는 **요일 / 시간대**
- 평균 세션 길이
- **진행률 · 완독률 추세**
- 월말 **읽다만 리포트**
  - 새로 시작 / 완독 / 보류
  - 베스트 인용 TOP 3

---

### 🧩 편의 기능
- **ISBN 스캔**, 제목 검색
- 표지 자동 불러오기 / 커버 색상 커스텀
- 저자 · 태그 · 진행률 · 최근 활동 기준 **검색 / 정렬 / 필터**
- 홈 **위젯 / 퀵 액션**
  - 이어서 읽기
  - 세션 시작
  - 빠른 메모
- **컬러 테마** (블루 / 민트 / 베이지)
- 다크 모드, 글꼴 크기 조절
- 데이터 **백업 / 복원**
- 다중 기기 동기화
- **CSV / Markdown 내보내기**
- 모든 기록은 **비공개가 기본값**  
  (공유는 사용자가 선택)

---

## 🔐 권한 안내 (선택)
- **카메라 / 사진 / 미디어**  
  → ISBN 스캔, 책 표지 이미지 업로드
- **알림**  
  → 리마인드, 목표 달성, 스트릭 안내
- **네트워크**  
  → 동기화 및 백업

선택 권한에 동의하지 않아도 핵심 기능은 이용할 수 있으며,  
일부 편의 기능만 제한될 수 있습니다.
